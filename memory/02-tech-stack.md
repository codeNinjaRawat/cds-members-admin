# Admin Dashboard – Tech Stack

> Inherits the shared stack in `../../memory/02-tech-stack.md`.

| Library | Used for |
|---|---|
| Next.js + TypeScript | App framework |
| Tailwind CSS + shadcn/ui | Styling and components (sidebar, dialogs, forms) |
| TanStack Table | Members and payments tables |
| shadcn Charts (Recharts) | Dashboard statistics |
| React Hook Form + Zod | Edit/approve forms |
| TanStack Query | Fetching data from BE |
| Sonner | Toasts |
| Motion | Subtle transitions only (no flashy effects) |
| Storybook, Vitest + RTL, Playwright | Design review and tests |
